# Caesar Cipher Tool 🔐

Welcome to my very first programming project! This is a simple command-line application that allows users to encrypt and decrypt text using the historic **Caesar Cipher** technique. 

I built this project to practice my coding fundamentals, get comfortable working in **VS Code**, and learn how to use **Git & GitHub** for version control.

## 🚀 Features
* **Encrypt Messages:** Shift letters forward by a custom key to scramble text.
* **Decrypt Messages:** Shift letters backward using the same key to decode secret messages.
* **Case & Symbol Protection:** Keeps spaces, numbers, and punctuation exactly as they are while only modifying alphabetical characters.

## 🛠️ Built With
* **Language:** python
* **Editor:** VS Code
* **Version Control:** Git & GitHub

## 📖 How It Works
The Caesar Cipher is a type of substitution cipher where each letter in the text is "shifted" a certain number of places down the alphabet. For example, with a shift key of `3`:
* `A` becomes `D`
* `B` becomes `E`
* `Hello` becomes `Khoor`
